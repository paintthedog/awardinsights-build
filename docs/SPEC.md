# Award Insights — working spec

Living spec for awardinsights.org. Read this before changing anything; update it when a decision changes.
Last updated 2026-10-20 (one site).

## What the site is
A free, public, static site (GitHub Pages, custom domain awardinsights.org) showing where federal research money goes to U.S. higher-education institutions, alongside peer groups the user chooses. Four tools in one site, tabs in this order:

| Tool | Path | Source | Data |
|---|---|---|---|
| Landing page | `/` | `site/landing.html` | `/shared/inst.json` |
| About | `/about/` | `site/about.html` | — |
| Federal Award Insights | `/federal/` | `page/head.html`, `page/body.html`, `scripts/build_fai.py` | USAspending trimmed files (`inputs/trimmed/`, `inputs/subawards/`, not in git), `inputs/ai-1-core/program_scope.json` |
| NSF Award Insights | `/nsf/` | `legacy/templates/tpl.html` | `inputs/nsf/{universe3,awards4,proginfo,coverage}.json` |
| Research Activity Designations | `/designations/` | `legacy/templates/dash_tpl.html` | `inputs/nsf/{rad5,climbers3}.json` |
| Research Portfolio Trends | `/portfolio/` | `legacy/templates/prof_tpl.html` | `inputs/nsf/profile4.json` |

The old addresses `/nsf.html`, `/designations.html`, `/portfolio.html` are redirect pages that keep the `#…` part, so shared links still open the same view. `legacy/landing/index.html` is the old landing page, kept only for the byte-for-byte check.

### One site (decided 2026-10-20)
- `scripts/build_shell.py` runs last on the built pages; the tool templates are not edited. It adds the site bar (wordmark → `/`, tabs Federal · NSF · Designations · Portfolio), moves each tool to its clean URL, writes the redirects and `/shared/` (`site.js`, `site.css`, `redirect.js`, `inst.json`). Sources in `site/`.
- Home page: short landing with one search across all tools and a line on each tool; choosing an institution opens the first tool that covers it (Federal for almost all).
- Search: each tool keeps its own "Find an institution" box; `site.js` adds hits from the other tools under "Not in <tool>".
- Selection carries between tools in the URL only (`#u=<id>`; nothing stored). Federal ↔ NSF also carry peers (`hold`, `up`, `x`; same format). Portfolio and Designations get `#u=` written for them when an institution is picked.
- When a tool doesn't cover the chosen institution it says so in one line ("X isn't in <tool>, which covers …") with links to the tools that do; the selection is kept.
- Each tool has one source line under its title (`SOURCES` in `build_shell.py`), naming the other tool where two count the same money differently: Federal = USAspending obligations by year; NSF = NSF's own award records at full intended value in the year made; Portfolio = HERD-reported R&D spending, not awards; Designations = Carnegie 2025, HERD, IPEDS. The landing page names each tool's source too.
- **NSF Award Insights stays a separate tool** (decided 2026-10-20), not folded into Federal; the source lines explain why their NSF figures differ.
- Light/dark switch (sun/moon, top right of the site bar): follows the system until someone switches; the choice is kept in that browser only (`localStorage` `ai.theme`, applied by `/shared/theme.js` in `<head>` so there's no flash); switching back to match the system forgets it. Charts take colors from CSS tokens, so they switch too.
- Shared files and Federal's `app.js` are linked with a content fingerprint (`site.js?v=…`, `app.js?v=…`) so a new build is never served from a stale browser cache.
- `inst.json` row: `[id, name, state, tools bitmask, {tool: its own id}]`. Federal keys system offices as `S-<UNITID>` where Portfolio uses the UNITID; these are linked automatically unless Federal also has the bare UNITID. Four institutes are linked by hand (`FED_SAME` in `build_shell.py`). Portfolio's six combined HERD units are carried as their main campus (first of `units`).

Owner preferences: no personal name on the public site; footer reads "© 2026 Award Insights. All rights reserved." No LLC for now.

## Repositories and deploy
- `paintthedog/awardinsights-build` (private): all source. The single source of truth.
- `paintthedog/awardinsights` (public): output only. `deploy.sh` force-pushes one fresh commit to its `gh-pages` branch. Never edit it by hand.
- **Pending switch:** the live site is still served from `main` of the public repo (the old hand-uploaded pages). After the first `./deploy.sh`, set GitHub → Settings → Pages → Deploy from branch → `gh-pages` / root.
- `./deploy.sh --dry-run` builds everything into `build/site/` and runs all checks. `COMPARE_LIVE=<checkout of the public repo's main branch>` checks the original pages, as `build_legacy.py` writes them (before the site bar), byte for byte against the old live pages: proof the tools' content didn't change by accident. Only pages in `SAME_AS_LIVE` are compared: Designations and the old landing page. NSF and Portfolio were changed on purpose on 2026-10-21 (directorates, divisions and agencies by acronym with hover; NSF's CSE shown as CISE; unnamed NSF program codes shown as "Unnamed NSF program" with the code on hover; Portfolio's "NIH / HHS" shown as HHS with the full name on hover).
- Checks that stop a deploy: `scripts/verify.py` (Penn State 214777, Howard 131520, NC A&T 199102, New Mexico 187985 totals recomputed from raw files with the zero floor), `verify_cliff.py 214777`, `verify_ic.py 198419 "ALLERGY|NIAID"`, `verify_sub.py` (subawards, when present).
- Work rule: one place edits at a time. Start a session by pulling; end it by pushing.

## Data rules (Federal Award Insights)
- Source: USAspending Award Data Archive, FY2022–26 assistance and contracts, 21 agencies (files dated 2026-09-06). Pull/trim with `scripts/usaspending_pull.py` / `usaspending_trim.py` on the Mac.
- Dollars are obligations per fiscal year (sum of each award's actions), not award values.
- Recipients: public and private nonprofit IPEDS institutions plus system offices, independent research institutes and foreign institutions as their own entities, via `inputs/ai-1-core/crosswalk/crosswalk_uei_v2.json`. For-profits (IPEDS sector 3/6/9) and hospitals are excluded. Peers, bands and ranks use the 3,282-institution Carnegie universe (`inputs/nsf/universe3.json`).
- Assistance: competitive project grants and cooperative agreements only (assistance types 04/05).
- Out of scope: formula/block grants, direct payments, loans, student aid — Education Title IV, HEERF (84.425), formula streams reported as project grants (FAIN P031B/E/K/D/P), and HRSA school-held student loan funds (93.342 HPSL/LDS, 93.364 Nursing Student Loans, 93.264 Nurse Faculty Loans; ~$215M).
- Earmarks (congressionally directed spending; identified by CFDA, FAIN series such as P116Z/S215K, or description) are listed and tagged but kept out of totals, ranks and peer comparisons.
- Contracts exclude FFRDC management-and-operating money (`ffrdc_exclusions.json` + description match); UARCs and university labs are kept, as HERD counts them.
- **Zero floor (changed 2026-10-21):** money pulled back from an award comes off the year it was given (latest year first), so no award and no single year goes below zero; a year shows what was obligated in it and not later pulled back. Totals are unchanged from the earlier rule (running balance floored at zero). Returns of money obligated before FY2022 (~$3.3B, mostly closeouts) are not subtracted. Why: under the old rule 5.4% of institution-agency-year cells were negative ($369M, mostly FY2025–26), and pullbacks don't reliably mean cancellations: in FY2025–26, 82% of assistance pullback dollars are routine revisions and 16% closeout adjustments, NIH pullbacks were lower in spring 2025 than in 2023–24, and only $2M mentions termination. Subawards follow the same rule. `verify.py` now checks every year as well as the total. An older year can shift slightly between refreshes as closeouts arrive. Awards whose only window activity is returning older money are not listed. Last-52-week funding per award is floored at zero. Negative "new award" actions are not counted as new awards.
- Agency routing: NIH is its own agency, split by institute/center (from awarding office, CFDA fallback; Office of the Director bucket). CDC, HRSA, SAMHSA, CMS are their own agencies, split by program (CFDA) with contracts in one row. "HHS other" holds ACF, ACL, FDA, ASPR, AHRQ, IHS, OS. NSF splits by directorate.
- Latest view: rolling windows (13/26/52 weeks) ending on the latest action date, compared with the same weeks a year earlier. The latest 8 weeks are provisional (Defense contracts report up to 90 days late); the briefing uses the settled window that leaves them out.
- Current annual funding = obligations in the last 52 weeks. Scheduled end = period-of-performance end on the most recent action (exposure, not expected loss).
- Deobligations do not track the 2025 grant terminations; do not use them as a termination signal.

## Explanations (decided 2026-10-21)
Tool titles stand alone: the explainer line under each title is removed (build_shell.py); "Sources (i)" sits under the title. `/about/` (`site/about.html`) covers the tools and their sources, how Federal counts money, peers, and terms of use; every page ends with a line reading "About Award Insights · Sources, methods and terms of use · © 2026 Award Insights. All rights reserved." Each tool's long methods paragraph (`.foot`) sits closed under "Methods and notes" just above it (site.js). Long explanations read as bullets (site.js `bullets()`): split at bold labels that start a sentence, else at " · ", else at sentences; any bullet over ~500 characters splits into its sentences. Write new explanations as short labeled sentences so they bullet cleanly. Keep the About page in step with this spec when a counting rule changes.
Keep explainer text out of the main view. Card subtitles (`.csub`), notes marked `.expl` and At a glance's "How these are measured" sit in a popover behind a small "i" after the card title (Federal: `infoize` in body.html; NSF and Portfolio: site.js). Each tool's source line is a "Sources (i)" disclosure under the title. What stays visible is what's needed to read the data: legends, short labels like "still being reported", and data notes such as earmarks not counted.

## Wording rules
Describe the data, never judge the institution: "Programs held by peers, not by X — a place to look, not a requirement"; "below/above", not "short/cushion"; no red/green verdict coloring. Peer comparisons are stated as medians.

## Design system
Young Serif for headings and names; Readex Pro for everything else, numbers included (lining, tabular figures; Young Serif's old-style digits read unevenly as statistics). Ground #f1efe8, paper #fff, accent teal #0f6f7c, "this institution" orange #e2611f (`--you`; text uses #c2501a for contrast). Light and dark themes via tokens; every page honors `data-theme` on `<html>`. Agencies and sub-agencies display by acronym with the full name on hover everywhere on the site (`agL`, `subL`, `AGFULL`, `SUBNAME`/`SUBAB` in body.html); dropdowns, which can't show hover text, read "NIH · National Institutes of Health". Programs display by title; the Assistance Listing number appears only on hover (`progL`) and in CSVs. CDC, HRSA, SAMHSA and CMS have no sub-agency level (`FLAT`): one row each; clicking opens their awards, and the By agency view lists their programs.

At a glance (decided 2026-10-21): one row per measure, each its own bordered card with space between; number (Readex Pro 600, 30px) in a left column centered top to bottom, label/sentence/details in the middle, the peer bar centered on the right; on phones the bar drops below. Sentence text muted so the number reads first.

Emphasis (decided 2026-10-21): bigger agencies first, smaller ones folded away. Institution "By agency" card: every agency with funding here or at a peer is its own row, largest first (a folded "Smaller agencies" row was tried 2026-10-21 and dropped: it didn't work visually). Inside an agency, sub-agencies with at least 5% of its dollars here (always the top three) get rows; the rest fold into "Other <agency> (N)". Site-wide views (Trends, Latest charts and tables, the By agency dropdown) lead with the seven largest grantmakers, NIH, NSF, DOD, ED, DOE, NASA and USDA (88% of the money; `BIGAG`); the others share one grey "Smaller agencies" band or row. CSVs keep every row. Rows where neither the institution nor any peer has funding are never shown (no "show all" toggle). "Peers funded" columns read as a share of peers with the count in parentheses, e.g. "56% (5)", so they can't be mistaken for the rank. The By agency card's legend sits above the bars, in two words per item.

Institution page order: header + KPIs → peer controls ("Peers — hold constant", tinted teal so it stands out: `--accent-soft` mixed into paper, teal-edged border) → At a glance (rows: number, sentence, peer bar) → Latest → Obligations by year → Scheduled to end → By agency and sub-agency → Subawards → Programs (held by peers not here / held here by few peers / above the peer median / earmarks; the complete list is in the Programs CSV). Every card can be minimized by clicking its title (remembered per browser). No Awards tab or Awards card (removed 2026-10-21 as too much): award lists open from an agency, sub-agency or program row, with "← Back" to the view that opened them; old `#v=awards` links still open the list.

## Protection
Data in separate files under `/federal/data/` (robots-disallowed), minified `app.js`, CSP `script-src 'self'`, build-time and browser-side text sanitizing, copyright string in page, script and every data file. The landing page has the same CSP. The three original tools are still single-file pages with inline data and inline script, so they can't take the CSP yet (to be brought in line).
